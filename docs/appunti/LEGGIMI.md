# Appunti sull'app

Qui finiscono gli appunti di chi prova l'app (Martina e il centro), scaricati da
Impostazioni → Appunti sull'app → "Scarica appunti nuovi (.md)".

1. Il titolare scarica il file `emovere-appunti_{data}.md` e lo salva in questa cartella.
2. Claude lo legge, applica le modifiche e scrive `risposte_{data}.md` con, per ogni appunto (id), cosa è cambiato o perché no.
3. Dopo il deploy il titolare segna gli appunti "Fatto" nell'app e incolla la risposta.

I file non devono contenere nomi o dati dei bambini: se un appunto ne contiene, toglierli prima di salvarlo qui.
